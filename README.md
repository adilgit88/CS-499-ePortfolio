# Adil Patel - Computer Science ePortfolio

This repository contains my Computer Science capstone ePortfolio. It presents original and enhanced artifacts that demonstrate growth in software design and engineering, algorithms and data structures, databases, security, testing, and professional communication.

## Technical artifacts

1. **Software Design and Engineering:** A C++ course planner refactored from a single-file program into a modular application with safer memory ownership, clearer responsibilities, stronger validation, and automated testing.
2. **Algorithms and Data Structures:** The same course planner enhanced from an ordinary binary search tree to a self-balancing AVL tree with measurable worst-case performance improvement.
3. **Databases:** A Python and MongoDB `AnimalShelter` data-access module enhanced with secure configuration, validation, indexing, structured results, lifecycle management, and 23 automated tests.

Each enhanced artifact contains a README with build, run, and test instructions.

## Security note

The original database artifact contained hard-coded credentials. The public portfolio copy redacts only those credential values so the original structure can still be compared with the enhanced implementation. Real `.env` files, passwords, tokens, and other secrets are excluded from the repository.
