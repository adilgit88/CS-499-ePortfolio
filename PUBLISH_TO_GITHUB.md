# Publish This Folder to GitHub

1. Create a new GitHub repository, for example `CS-499-ePortfolio`.
2. Open GitHub Desktop and choose **Add an Existing Repository from your Hard Drive** after placing this folder where you want it.
3. If GitHub Desktop says the folder is not yet a repository, choose **Create a Repository** for this folder.
4. Use `main` as the default branch.
5. Commit all files with a message such as `Add final CS 499 ePortfolio`.
6. Publish/push the repository to GitHub.
7. On GitHub, open **Settings > Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/ (root)`.
10. Save and wait for GitHub Pages to publish.
11. Open the published site and test every navigation link.
12. After recording the code review, edit `code-review/index.html` and replace the video placeholder with your hosted video link.

## Before final submission

Do not add a real `.env` file. Do not add passwords, tokens, API keys, or private database connection strings.
