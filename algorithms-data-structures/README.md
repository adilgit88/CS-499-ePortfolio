# Algorithms and Data Structures Enhancement

This section shows the progression of the C++ Course Planner from an ordinary binary search tree to a self-balancing AVL tree.

- [Original Course Planner](original-course-planner/) - original single-file implementation preserved for comparison.
- [Modular BST baseline](baseline-modular-bst/) - software-engineered BST version used as the starting point for the algorithm enhancement.
- [Enhanced AVL implementation](enhanced-avl/) - self-balancing tree with rotation tests, structural validation, stress testing, and a measurable performance comparison.
- [Enhancement narrative](narrative.md) - explains the algorithm choice, complexity, trade-offs, testing, feedback, and professional growth shown by the enhancement.

With 1,000 sorted keys, the comparison program measures an unbalanced BST height of 1,000 and an AVL tree height of 10.
